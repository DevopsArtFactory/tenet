Tenet v1 Architecture

Tenet is a repository-driven deployment control plane for multi-account AWS environments. It turns desired deployment intent and runtime status into operator-friendly read models and a drill-down UI.

Desired state

  • Repository-backed manifests define what should run
  • Catalog compilation turns that into a stable internal model

Runtime state

  • Status is stored separately from desired configuration
  • Sync, health, rollout, conditions, and history remain explicit

Operator experience

  • UI is designed around drill-down, not dense dashboards
  • Applications overview narrows into application and resource detail
