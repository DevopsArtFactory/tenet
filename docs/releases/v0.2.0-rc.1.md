# Tenet v0.2.0-rc.1 — native ECS early access

This release candidate is intended for local evaluation and controlled sandbox
trials. It adds native ECS GitOps execution and recovery to the operator UI.
It does not claim live AWS production qualification.

## Capabilities

- Reviewed native Rolling, Blue-Green, Canary and Linear deployments for existing
  ECS services, with separately enabled live and advanced-strategy execution.
- Git revision polling, SHA-bound plans, optional self-heal, and desired-count
  changes for all supported strategies.
- Manual and automatic failure recovery to the captured previous revision and
  desired count, including durable restart checkpoints.
- GitHub OAuth, Google OIDC and Okta OIDC login with repository-scoped RBAC.
- AWS Emulator CI covering advanced strategies, failures, count restoration,
  Git-to-Apply execution and restart recovery without real AWS resources.

## Security and migration

Authentication/RBAC flags no longer imply trusted proxy headers. Managed-login
installations should leave `TENET_API_TRUST_AUTHENTICATED_HEADERS=false`. A trusted
proxy deployment must enable it explicitly and strip incoming identity/grant
headers. Restart any login transaction started before the browser-binding fix.

OAuth state consumption and identity updates now use process-safe file locks.
Browser return paths reject ambiguous separators and control characters. HTTP
requests have body, header and transport time limits; see the
[local runtime guide](../architecture/tenet-v1-local-runtime.md).

Compose publishes API and Redis ports only on loopback. The AWS bootstrap now
requires an HTTPS certificate, hostname, GitHub login secrets and explicit
operator CIDRs; it defaults to an internal ALB. The broad AWS `ReadOnlyAccess`
attachment is removed: configure explicit observer roles even for same-account
inspection. See the [bootstrap upgrade instructions](../../deploy/terraform/aws-central-control-plane/README.md).

The source requires Go 1.27.4 or later and includes patched AWS EventStream/Logs
dependencies. CI scans reachable Go vulnerabilities on every PR and weekly.

## Try it

Download the source archive and `SHA256SUMS` from this release, verify with
`shasum -a 256 -c SHA256SUMS` (also download `SOURCE_COMMIT`), and follow the
[local walkthrough](../guides/getting-started.md). Source and the checked-in
Dockerfile are the supported distribution paths for this candidate.

## Validation limits

Live AWS sandbox runs and live identity-provider verification remain pending.
Emulator success is not evidence of AWS IAM, ALB timing, capacity or networking
behavior in a real account. EC2 support remains catalog, planning and inspection.
Use persistent shared store paths with supported OS file locking; independent
local stores across replicas do not coordinate execution.

Release metadata records the exact source commit and its passing CI run.
